把每个按钮都做成一个小故事，逐个加进这张页面里。

01

Submit Celebration

点击后经历按压、思考、彩带喷溅和成功落定，最后丝滑回到初始态。

状态节奏 Pressed → Thinking → Celebrate → Success

交互方式 点击按钮开始，成功态结束后自动回到初始态。

02

Create Note Morph

默认是粉色按钮，hover 会轻微下沉；点击后形变成你 Figma 里的 note creation area，底部 icon 错峰进入。

状态节奏 Hover Sink → Press → Morph → Icons Stagger In

交互方式 点击粉色按钮展开，展示完成后自动收回到按钮态。

03

Liquid Split

默认是黑色 Enter 圆按钮，点击后会像液体一样回弹，再从本体分离出四个小圆按钮。

Enter S M L XL

状态节奏 Press → Liquid Rebound → Sticky Split → Return

交互方式 点击主按钮后展开四个液态圆按钮，继续点击小圆也会有液体回弹；无操作一会儿后自动回到初始态。

04

Reader Controls

默认是右下角菜单图标，点击后淡出，整组控制菜单从同一个右下角位置展开。

状态节奏 Trigger Fade → Bottom Right to Top Left Reveal → Gentle Collapse

交互方式 展开后每个选项都可点击并有克制反馈，无操作一会儿后会按一致节奏收回。

05

Notion Face

鼠标移上去时眼睛和眉毛会跟着视线移动，带一点灵动的挑眉表情。

状态节奏 Hover Tracking → Eyebrow Lift → Gentle Settle

交互方式 鼠标移动时表情会跟随视线变化，点击时还有一个很轻的落位反馈。

06

Delete

默认是极简白色删除按钮，hover 只做克制选中感；点击后轻微下压，短线滑入垃圾桶，桶盖短暂打开后再合上。

状态节奏 Hover Select → Press Down → Lid Open → Toss In → Close → Rebound

交互方式 按下后按钮只做很轻的下沉，短线从左滑入垃圾桶，桶盖在中段短暂打开，线条入桶后立刻关闭并回到静止。
